# SOS Heat — «Грелка» 🔥

Небольшой экспериментальный сайт, который создаёт **ограниченную вычислительную нагрузку** на CPU телефона с помощью Web Worker.

## Запуск

Открой GitHub Pages для репозитория или запусти `index.html` локально в современном браузере. Никаких библиотек, аккаунтов, рекламы или аналитики.

## Что умеет

- Регулировка интенсивности от 5% до 20% (короткие вычислительные импульсы с паузами).
- Сеанс максимум 15 секунд.
- Аварийная остановка.
- Автоматическая остановка при сворачивании/скрытии вкладки.
- Не блокирует интерфейс: вычисления выполняются в Web Worker.

## Важная безопасность

Это **не настоящий обогреватель** и не способ безопасно греть аккумулятор. Фактическая температура не считывается: стандартные браузеры не дают надёжного доступа к температуре CPU или батареи. Нагрев зависит от модели телефона, браузера и условий и может быть незаметным.

Не запускай тест на уже нагретом телефоне, во время зарядки, под подушкой или на солнце. Не используй телефон для обогрева тела и не пытайся быстро нагревать холодный аккумулятор. Не оставляй тест без присмотра; останови его при любом заметном нагреве или системном предупреждении.

Проект работает локально в браузере и не отправляет данные.
